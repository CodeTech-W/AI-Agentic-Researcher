
# AI Agentic Researcher System

## Project Overview
AI Agentic Researcher is a Python-based research assistant designed to simplify academic research through research paper retrieval, PDF analysis, and automated research document generation.

## Project Objectives
- Search academic research papers.
- Analyze research documents in PDF format.
- Generate structured research content.
- Automate research workflows using AI agents.

## Technologies Used
- Python
- Streamlit
- LangChain
- LangGraph
- Groq
- Ollama
- arXiv API
- PyPDF2
- LaTeX

## Key Features
- Research paper search using arXiv.
- PDF document analysis.
- AI-powered research assistance.
- Research workflow automation.
- Research document generation.
- PDF output generation.

## Installation and Setup
1. Clone the repository.
2. Open the project folder.
3. Create and activate a Python virtual environment.
4. Install the project dependencies.
5. Configure the required environment variables.

## How to Run
```bash
streamlit run frontend.py
```
